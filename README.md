# 世界织卷 · MC 指令与资源工具箱

当前版本：**2.0.3**

Minecraft 工具箱风格的单页应用：进入动画、首页、启动器、资源、我的、百宝箱、账号登录 / 注册、每日中心、货币 / 商店 / 背包与好友聊天，另附独立的**账号密码管理后台**。

## 应用名称与图标

- **应用名称**：世界织卷 · MC 指令与资源工具箱
- **图标**：深绿极光底 + 大号等距草方块 + 金色 W 织线 + 命令提示符徽章，源文件为 `assets/app-icon.svg`

## 快速启动

```bash
# 静态页面（账号密码本地注册即登录，不依赖服务）
python -m http.server 8787

# 需要微软 / Xbox 登录或在线好友时，再启动账号服务
node server/server.js
# 打开 http://127.0.0.1:8787/
```

> **账号密码注册 / 登录不需要账号服务**：注册即登录，数据保存在当前设备；微软 / Xbox 登录才需要服务端 `MS_CLIENT_ID` 与账号服务。

## 登录 / 找回密码

| 方式 | 说明 | 依赖 |
| --- | --- | --- |
| 账号密码 | 在登录页自行注册账号 + 密码，本机即注册即登录；密码 SHA-256 加盐哈希 | 不需要服务 |
| 微软官方 | 标准 OAuth 2.0 设备码流程 → Xbox Live → XSTS → Minecraft 档案 | 需要 `MS_CLIENT_ID` |
| Xbox 官方 | 同上，使用 Xbox Live 官方授权链路 | 需要 `MS_CLIENT_ID` |

- 未登录时登录页只显示账号密码注册 / 登录，可随时返回。
- **登录成功后**，才能在「我的 → 切换账号」中使用微软 / Xbox 官方登录。
- **忘记密码**：登录页 →「忘记密码？」→ 联系作者本人；页面提供作者 QQ 与官方 QQ 群。作者会核对账号名称、UID、注册时间与皮肤，不会索要密码或验证码。
- 签到、每日任务、每日答题、好友都要求先登录，但不限制账号类型。
- 每个账号的等级、经验、任务、答题、签到数据按 UID 独立保存。

  - 读取系统下载路径（`WWShell.getDownloadPath()`）
  - 显示 APK 与全部下载文件，点击可打开
  - 原生壳使用 `listFiles(path)` / `listApkFiles()`；浏览器会请求选择一个文件夹后读取
- **导出统一到下载路径**：`.schem`、更新 APK、点阵字、像素画全部写入 `getDownloadPath()` 返回的下载目录；不再弹出「另存为」或允许改到其他文件夹。

## 数据与安全

- 账号密码保存在本机 `localStorage`，密码以随机盐 + SHA-256 存储；不请求账号服务。
- 微软 / Xbox 令牌由账号服务签发；服务端不保存明文密码。
- 设置、搜索历史、登录令牌、签到 / 经验 / 任务 / 答题状态、BGM 进度、生成 / 导出历史按本机 / 账号 UID 保存。
- 导入的音乐保存在 IndexedDB，不上传；只会读取用户主动选择的音频文件。
- 内置四首音频随 APP 打包；请确认你拥有相应的使用与分发权利。
- 存储权限只在原生壳导出文件 / 扫描设备时按需申请；浏览器内使用下载或用户选择的文件夹。
- 原生壳接口：
  - `WWShell.requestStoragePermission()`
  - `WWShell.saveFile(filename, base64, mime, path)`
  - `WWShell.fileExists(path)`、`WWShell.openFile(path)`
  - `WWShell.listInstalledApps()`、`WWShell.launchApp(packageName)`
  - `WWShell.installFile(path)`（更新包安装）
  - `WWShell.checkUpdate()`（可选，返回更新 manifest）
- 历史记录里的「检测 / 打开」在原生壳中通过 `WWShell.fileExists()` / `WWShell.openFile()` 检查文件；不存在时提示重新导出或复制下载。
